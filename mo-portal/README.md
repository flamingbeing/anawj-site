# Baby MO Portal

Test and (later) discussions for new anaesthesia MOs. Static page, no build step.

- Try it: open `index.html` through any static server with `?demo` (e.g. `…/mo-portal/?demo`). Demo passphrase: `demo`;
  "Faculty" opens the editor with sample questions. Everything stays in the browser.
- Shared mode needs the Firebase project in `SETUP.md`; paste its config into `js/firebase-config.js`.
- How it works and why: `NOTES.md`. Tests: see "Tests" there.
