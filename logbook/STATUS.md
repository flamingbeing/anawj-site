# Logbook status

Current work, what waits on the owner, the queue and the dated decisions log are kept in the owner's private notes
(details in the owner's private notes). Public record: the pull request list filtered by the `logbook` label.

Lasting rules and lessons are in [NOTES.md](NOTES.md); the data model is in [README.md](README.md). Sessions: use your own
file under `status/` for what is half-done (branch or PR, how to resume) and delete it when the session ends; the
work-in-progress folder convention is in [status/wip/README.md](status/wip/README.md).
